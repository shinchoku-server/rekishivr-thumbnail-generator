# 歴史VR サムネ作成ツール

歴史VRのSNS投稿画像とブログ・CMS用サムネイルを、ブラウザで作成するツールです。テンプレートに文章と写真を入れるだけで、書体や余白をそろえた画像を書き出せます。

## 起動方法

macOSで `index.html` をブラウザで開きます。インストールやビルド、ローカルサーバーの起動は不要です。文字の描画には、Mac標準のヒラギノ角ゴシックとHelvetica Neueを使用します。

## 使い方

1. 編集したい画像のプレビューをクリックし、編集欄に文章を入力します。
2. SNS画像を増やすには「ページを追加」を押します。「タイトル」「写真＋文」「写真」「項目」「ロゴ」の5種類から用途に合ったテンプレートを選べます。
3. 写真欄に画像をドロップするか、クリックしてファイルを選びます。スライダーで拡大率を調整し、プレビューをドラッグして位置を合わせます。帯の色は投稿全体または画像ごとに設定できます。
4. ブログ・CMS用の画像を作る場合は「ブログ用も作る」をオンにします。SNSの最初の文と写真を使うか、ブログ用に個別に設定できます。
5. 編集欄の保存ボタンで1枚ずつダウンロードできます。まとめて保存する場合は、画面上部の「すべて保存（ZIP）」を押します。

大きい文の一部を `【】` で囲むと、その部分が反転します。1行全体を囲むと、その行が大きな帯になります。

## 出力形式

| 用途 | サイズ | ファイル名 |
| --- | --- | --- |
| SNS投稿 | 1080 × 1080 px | `square_1.png`、`square_2.png` など |
| ブログ・CMS用 | 1920 × 1080 px | `blog_thumbnail.png` |
| 一括保存 | PNGをZIPに格納 | `thumbnails_YYYYMMDD.zip` |

文章や写真の編集内容は、ページを再読み込みすると初期状態に戻ります。ページを閉じる前に、必要な画像を保存してください。
